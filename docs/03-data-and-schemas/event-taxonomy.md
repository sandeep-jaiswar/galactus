# Galactus — Event Taxonomy

## Purpose of This Document

This document defines the **event taxonomy** used by Project Galactus.

It exists to:
- Establish a shared vocabulary for market events
- Enable consistent inference across time and data sources
- Prevent ambiguous or overloaded interpretations of market changes

All inference in Galactus is grounded in **events**, not continuous streams.

---

## Core Principle

An event represents a **discrete change in market constraints or capital behavior**.

Events are:
- Time-bound
- Causally meaningful
- Replayable
- Interpretable

Anything that cannot be framed as an event does not belong in the core system.

---

## Event Classification Overview

Galactus classifies events into five primary categories:

1. Market Structure Events  
2. Positioning Events  
3. Liquidity Events  
4. Information Events  
5. System Events  

Each category has distinct semantics and handling rules.

---

## 1. Market Structure Events

### Definition

Events that impose **hard, externally defined constraints** on market participants.

### Examples

- Options expiry (weekly / monthly)
- Futures settlement
- Index inclusion or exclusion
- Index weight rebalancing
- Trading halts or regulatory changes

### Characteristics

- Known in advance
- Time-deterministic
- High confidence
- Often create forced capital behavior

### Inference Role

Market structure events define **when capital loses optionality**.

---

## 2. Positioning Events

### Definition

Events that reflect **material changes in exposure or risk positioning**, particularly in derivatives.

### Examples

- Significant changes in open interest
- Strike concentration shifts
- Gamma exposure regime transitions
- Rapid buildup or decay of positions

### Characteristics

- Observable via public data
- Often precede price movement
- Indicative of hedging requirements

### Inference Role

Positioning events reveal **latent pressure** before resolution.

---

## 3. Liquidity Events

### Definition

Events that materially alter the **market’s ability to absorb capital flows**.

### Examples

- Delivery spikes
- Volume exhaustion
- Sudden drops in participation
- Liquidity cliffs near key levels

### Characteristics

- Often asymmetric
- Can amplify otherwise modest flows
- Highly context-dependent

### Inference Role

Liquidity events modulate the **impact** of capital pressure.

---

## 4. Information Events

### Definition

Events that introduce new public information into the market.

### Examples

- Corporate earnings releases
- Corporate action disclosures
- Regulatory announcements

### Characteristics

- Public and timestamped
- Content is secondary to reaction
- Can interact with existing constraints

### Inference Role

Galactus observes **capital response**, not narrative meaning.

---

## 5. System Events

### Definition

Events generated by Galactus itself or its infrastructure.

### Examples

- Data ingestion failures
- Delayed data arrival
- Schema version changes
- Model version updates

### Characteristics

- Internal
- Non-market in origin
- Must be surfaced explicitly

### Inference Role

System events affect **confidence and validity**, not market behavior.

---

## Event Attributes (Canonical)

All events must include:

- Event type
- Event timestamp (event time)
- Source
- Affected instruments
- Confidence or completeness indicator

Optional attributes must be documented and versioned.

---

## Event Time Semantics

- Event time represents when the event occurred in the market
- Processing time represents when Galactus observed the event

Inference must align strictly to **event time**.

Late or missing events must be handled explicitly.

---

## Event Granularity

Galactus prefers:
- Coarser, meaningful events
- Over fine-grained noise

Granularity must be:
- Justified by inference value
- Consistent across time
- Documented

---

## Event Immutability

Once emitted:
- Events are immutable
- Corrections are new events
- Deletions are forbidden

This guarantees replayability and auditability.

---

## Why Taxonomy Matters

Without a strict taxonomy:
- Events become ambiguous
- Causality becomes unclear
- Inference degrades into pattern-matching

The taxonomy enforces **structural thinking**.

---

## Final Statement

**Galactus understands markets by understanding events.**

Everything else is noise.
