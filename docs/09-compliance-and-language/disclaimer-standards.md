# Galactus — Disclaimer Standards

## Purpose
Define mandatory disclaimer language to prevent misinterpretation and maintain SEBI regulatory safe harbor.

---

## Core Rule
Galactus outputs are **informational only**.

---

## Mandatory Disclaimer Elements

- No investment advice
- No trading recommendation
- No profit expectation
- No personalization

---

## Placement Rules

- API responses
- Dashboards
- Reports
- Documentation
